수집 방법

Playwright → Facebook Ad Library 크롤링.
8개 계정 순차 실행.

displayed_meta_count

화면 상단 "결과 ~N개" 파싱값.
Chat 리포트 공식 수치. written(행 수)와 절대 혼동 금지.

30일 초과 광고

ad_start_date < today − 1 month
정확히 한 달째는 포함 안 함.

전일 대비 증감

meta_ad_counts 탭 기준.
이전 calendar date와 비교 (+N / −N).
같은 날 재실행은 비교 제외.

저장 탭 2개

meta_ad_start_dates
→ 광고별 ID · URL · 시작일 · 소재

meta_ad_counts
→ 날짜별 / 경쟁사별 총 광고 수
